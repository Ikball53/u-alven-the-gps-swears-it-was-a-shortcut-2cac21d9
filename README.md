## The GPS Swears It Was a Shortcut

The GPS blames the map for a shortcut through a lake, with wedding guests mistaking the headlights for part of the ceremony. Smug, defensive, first-person GPS voice — 144 characters.

Entry line (144 characters): "Blame the map, not me: it promised me a shortcut through the lake, and the wedding guests still think your headlights were part of the ceremony."

`main.py` writes the exact line (no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
